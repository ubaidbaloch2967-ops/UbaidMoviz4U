UBAID MOVIZ4U - UPDATED FILES

1. Upload these files into the root of your GitHub repository, replacing the old versions:
   - index.html
   - Movies.html
   - Furiosa.html
   - home.html

2. Keep the spelling and capitalization exactly the same. GitHub Pages is case-sensitive:
   Movies.html is different from movies.html.

3. Movies.html loads trending movies and posters from TMDB and supports search, pagination,
   poster fallback, animated poster hover, movie details, and a copyable official-options search link.

4. TMDB API key is visible in client-side code. For a public static site this key is not secret;
   restrict it in TMDB settings if possible. If requests fail, verify the key and TMDB API access.

5. This site links to search results for official/licensed streaming, rental, purchase, or download
   options. It does not provide unauthorized copies of copyrighted movies.
